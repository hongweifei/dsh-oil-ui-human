# 游玩设计与强手感操控规范

## 适用范围

本规范适用于小游戏、抽奖、扭蛋、计时养成，以及旋钮、拉杆、摇杆等强手感操控交互的界面设计。此类场景中，互动过程本身就是产品核心体验：用户期待观察转轮减速过程、硬币被推出瞬间、娃娃差点滑落的紧张时刻。此类界面须优先阅读本文档，其余设计规范照常适用。

## 过程即玩法

### 演出时长控制

演出动画时长可超越常规界面切换的限制。例如三个转轮依次停下的动画总时长约两秒，不必因"超过五百毫秒可能导致等待感"而强行截短。

### 状态持久化保障

完成付费或产生结果后立即执行数据持久化：刷新操作不丢失进度、不会重复扣费、奖励仅结算一次。具体持久化时机应依据玩法规则确定。

### 交互锁定机制

演出期间须明确标示哪些操作处于锁定状态；连续点击不应触发重复扣费。

### 手势识别规则

旋钮、拉杆等手势操作应从按下位置开始跟随追踪，经过生效点方计为有效操作，未到达生效点即松开时不计费。

### 辅助模式兼容

启用"减少动态效果"选项时，玩法逻辑仍按正常流程计算结果，仅视觉表现直接到位；不得因该选项而停止玩法本身。

### 手感评估标准

手感质量应以录屏为依据进行判断：分析减速是否连续流畅、停下时是否存在顿挫、收益反馈路径是否清晰明了。静态三帧截图仅能说明状态信息，不足以评估整体手感。

## 素材与渲染规范

### 核心素材管理

角色、藏品、道具、符号和材质贴图为此类界面的核心元素，默认采用图像生成方式制作。动手前应先列出完整素材清单。手写 SVG 与 CSS 仅适用于绘制界面图标和简单图形，用于绘制角色和道具时会落入图标包的质感局限。成套素材制作流程参见 [素材指南](media.md) 中的"成套素材：角色、道具与图集"一节；宿主环境不具备图像生成能力时，应按同一份文档提交素材需求简报，不得使用手绘图形冒充成品。

### 物理仿真场景

当乐趣来源于空间关系和物理模拟时（如堆叠、碰撞、推挤、摆动效果，或透明、金属材质表现），应采用实时三维引擎渲染场景。生成的图像作为贴图和精灵使用，具体方法参见 [素材指南](media.md) 中的"实时 3D"一节。树木生长、天气变化等自然演变过程，采用成套生成图像通常效果更佳。

### 场景集成验证

将素材放入场景后须重新审核视觉效果：确保受光方向与场景一致、存在接触阴影、侧面背面及翻落状态下不露出纸片边缘。图像生成完成并不等同于可直接用于场景，必须通过场景集成验证方可投入使用。
