# 风格对比页

风格对比页用于将若干候选方案置于同一页面中并列比较，由用户作出选择。用户能够并列或单张查看、按实际尺寸观看、选定并复制方向说明。对比页的外壳只承担比较与挑选职能，本身不带风格倾向，也不作为候选方案的参考来源。

各候选方案的核心内容、主要动作和目标用户应保持一致，差异体现在构图、信息组织方式、字体气质、色彩关系、疏密程度和用图方式上。候选数量依据用户的期望数量和实际存在差异的数量确定，不通过复制整个产品来凑数。

## 准备输入

一轮只生成一个对比页。候选能够运行时优先使用真实页面：单独编写的 HTML 小样直接嵌入，项目内的方案使用本机地址，只有在无法取得可运行页面时才使用截图。每个方案对应一个画面：存量项目选取入口或差异最大的那一步，整站方案只放置代表页。

撰写 `manifest.json` 与候选文件。`source` 的相对路径以 manifest 所在目录为基准；候选所引用的图片、字体、视频、CSS 和脚本，以引用它的文件所在目录为基准，也可以使用绝对路径。目录之外的本地文件同样会自动内嵌，无需复制；单文件上限 20 MiB，输入文件总量上限 100 MiB，不引用网络资源。HTML 缺少 `head` 时会自动补充。manifest 的最小写法如下，尖括号内替换为本轮候选的实际内容，方向取自方向卡：

```json
{
  "schemaVersion": 1,
  "project": "<项目名称>",
  "brief": "<所有候选共同表达的内容与主要任务>",
  "round": "<轮次，例如 01>",
  "candidates": [
    {
      "id": "<小写唯一标识>",
      "name": "<方向名称>",
      "concept": "<北极星：一句能够指导取舍的体验意图>",
      "typography": "<实际使用的字族、字重与尺度关系>",
      "palette": ["<十六进制色值>", "<十六进制色值>", "<十六进制色值>"],
      "traits": ["<可观察特征>", "<可观察特征>"],
      "source": "<候选文件的相对路径>"
    }
  ]
}
```

| 情形 | manifest 中的附加写法 |
| --- | --- |
| 固定画布的界面，不随宽度重排 | 在顶层或候选内写 `"nativeViewport": "<宽>x<高>"`。对比页按该视口渲染，再整体等比缩放，候选自身无需编写缩放逻辑 |
| 自行编写的可操作小样 | 候选增加 `"interactive": true` |
| 项目中需要运行才能查看的页面 | 候选的 `kind` 设为 `"url"`，使用 `url` 指向本机开发服务器；顶层使用 `serve` 写明启动命令 |
| 改动已有页面 | 将现状一并纳入，增加 `"baseline": true` |
| 仅有截图 | 候选的 `kind` 设为 `"image"` |

字段与限制以 `oil_ui_explorer` 的参数说明及本页 manifest 示例为准。

`palette` 推荐写作十六进制色值数组；写作包含色值的描述文字或对象时，生成器会提取其中的颜色，只有在完全没有有效色值时才报错。

## 生成与打开

调用 `oil_ui_explorer` 生成对比页：

```json
{
  "manifest": "explore/manifest.json",
  "out": "style-explorer.html"
}
```

`manifest` 可传 `manifest.json` 的相对路径，也可直接传 JSON 对象；不传时工具会自动查找工作目录下的 `manifest.json` 或 `explore/a.html`、`b.html`、`c.html`。对比页默认生成在工作目录根部的 `style-explorer.html`，并返回预览地址 `explorerUrl`。输入有误时，工具会一次性列出全部需要修正之处，按提示修改后重新调用。组装失败时，将 manifest 和候选留给用户直接查看，说明对比页尚未组装完成，不临时另写一套工具。

存在本机地址候选时，交付时应保持开发服务器处于运行状态。用户随后要求"打开对比页"时：读取 manifest 中的 `serve`，在 `cwd` 指定的目录中后台执行 `command`，待 `url` 可以访问后再打开对比页。

## 记录用户选择

用户点击"选择"会复制一句话，例如"<轮次>：选 03 <方向名>"。用户粘贴该句或直接说明选择之后，按轮次和编号对照当前 manifest，确认属于本轮，将选择与备注更新至设计说明，再回到生成该对比页的流程继续执行。对比页不会写回任何文件，也不会自动向代理发送消息。

交付前应对候选目录执行一次 `oil_ui_shoot({ "target": "explore", "size": "desktop", "thumb": true, "out": "shots/explore" })`（一次输出各候选缩略图与并排总览图 `sheet.png`）核对候选：每张画面与 manifest 中所写的页面、状态、视口一致，中文字体确实完成了渲染。判断文字大小和细节时使用单张查看模式下的"实际尺寸 100%"，适应窗口的缩小图不能作为可读性通过的证据。对比页自身的功能由 Skill 自带的测试保证，任务中不重复验证、不读取模板源码。
